# Methodology notes

## Evidence labels

- **Calculated**: a direct calculation from supplied inputs.
- **Model-derived**: generated by a named model/version and recorded with the analysis.
- **Experimental**: entered or imported from an assay.
- **Unavailable**: the required input was not present; no default confidence is substituted.

## Priority score

The score is a weighted, explainable computational ranking. It must not be interpreted as experimental success probability.

## Failure analysis

Patterns are reported as associations within the available outcome cohort. Causal interpretation requires follow-up experiments and validation.
